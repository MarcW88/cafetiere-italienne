# Evidence packet — Bialetti Mini Express

Date : 2026-09-17
Workflow version : 2

## Primary evidence

### Mini Express classique actuelle

Source : https://www.bialetti.co.nz/products/bialetti-mini-express-black

- aluminium alimentaire ;
- 2 tasses ; rendement préparé approx. 90 ml ;
- base approx. 8,0 cm ;
- le café sort directement vers les tasses via deux becs ;
- la plaque support en aluminium réchauffe les tasses pendant la préparation ;
- gaz, électrique, céramique ; pas induction directe ; adaptateur induction possible ;
- remplir la base juste sous la soupape ; café espresso/moka moulu, non tassé ; chauffe faible à moyenne ;
- retirer du feu dès la fin de préparation ;
- lavage manuel, pas de lave-vaisselle ;
- trois premières préparations recommandées à jeter ;
- la référence vérifiée ne comprend pas les tasses ; Bialetti indique que la plupart des petites tasses espresso peuvent convenir sous les becs.

### Mini Express Induction 2 tasses vérifiée

Source : https://www.bialetti.co.nz/products/bialetti-mini-express-induction-2-cup-set

- 2 tasses ; rendement préparé approx. 90 ml ;
- base bi-layer : extérieur inox + intérieur aluminium ;
- base approx. 9,5 cm sur cette fiche régionale ;
- compatible induction, gaz, électrique et céramique ;
- deux tasses noires incluses sur le set vérifié ;
- même logique : eau juste sous la soupape, café non tassé, chauffe faible à moyenne ;
- lavage manuel et trois premières préparations à jeter.

### Corroboration européenne Mini Express Induction

Source : https://bialetti-shop.de/Espressokocher-Edelstahl-Induktion/mini-espress-induktion.html

- service direct dans deux tasses ;
- chaudière bi-layer compatible induction ;
- diamètre de base annoncé approx. 9,2 cm ;
- deux tasses de 90 ml incluses.

La différence 9,2 vs 9,5 cm est traitée comme approximation régionale / de mesure. La page ne fige pas un diamètre universel au millimètre et demande de vérifier le diamètre minimal détecté par la plaque.

## Contradictions / scope resolution

- Le bénéfice « tasses réchauffées » décrit une conséquence de la plaque support ; il ne prouve pas une meilleure extraction.
- La Mini Express classique et l'Induction sont deux constructions distinctes sous une même famille.
- Les diamètres induction ≈9,2 et ≈9,5 cm ne sont pas artificiellement fusionnés en une valeur exacte universelle.
- Les tasses incluses varient selon le set : ne pas écrire que toute Mini Express est systématiquement livrée avec deux tasses.
- Les pièces documentées pour la classique aluminium ne sont pas étendues à l'Induction sans preuve.

## Decision impact

La page doit permettre au lecteur de choisir :
1. Mini Express classique ou Induction ;
2. en comprenant que 2 tasses correspondent à ≈90 ml total ;
3. parce qu'il valorise réellement le service direct dans deux tasses ;
4. en vérifiant la détection de sa plaque si induction ;
5. en contrôlant le contenu exact du set et la compatibilité des pièces ;
6. en sachant qu'un débit asymétrique est un signal utilisateur possible, pas une propriété garantie du produit.
