# Brief — cafetiere-italienne-induction

- Query : cafetière italienne induction
- Intention : choisir un modèle réellement compatible avec une plaque induction.
- Décision : éviter les faux raccourcis matériau/gamme et vérifier la taille exacte.
- Scope : Venus, Moka Induction, Brikka Induction, Alessi 9090, Alessi Vite.
- Critères : fond magnétique, diamètre/détection, taille, construction, spécialisation.
- Verdict attendu : Venus 4/6 par défaut ; alternatives selon priorité.
- Fait critique : Venus 2 tasses non adaptée à l’induction ; petits diamètres à vérifier sur la plaque.
- Anti-patterns : pas de “tout inox = induction”, pas de puissance de plaque inventée, pas de classement générique copié depuis la page principale.
- Maillage : guide compatibilité induction, comparatif général, petite cafetière.
- Structure : réponse → piège technique → profils → adaptateur → sources.
