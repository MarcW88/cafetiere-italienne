# Brief — cafetiere-italienne-design

- Query : cafetière italienne design
- Intention : choisir une moka comme objet de cuisine autant que comme outil.
- Décision : comparer des langages de design, pas fabriquer un score universel.
- Scope : Alessi 9090, Vite, Pulcina, La Cupola.
- Critères : identité formelle, fonction, compatibilité, niveau de gamme.
- Verdict attendu : 9090 iconique/fonctionnel ; Vite contemporain 2026 ; Pulcina sculptural ; La Cupola architectural.
- Preuves obligatoires : designers, matériaux, induction lorsque documentée, année de lancement pertinente.
- Anti-patterns : pas de score esthétique ; pas de lien automatique prix = meilleur café ; structures produit non symétriques.
- Maillage : comparatif général, inox, induction.
- Structure : réponse non-classée → quatre directions → tableau par contexte → limites de la comparaison → sources.
