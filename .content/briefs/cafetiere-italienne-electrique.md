# Brief — cafetiere-italienne-electrique

- Query : cafetière italienne électrique
- Intention : choisir une moka autonome sans plaque.
- Décision : distinguer capacité et fonctions électriques réelles.
- Scope : Ariete 1368, Ariete 1358, De’Longhi Alicia EMK6.
- Critères : capacité, arrêt auto, maintien au chaud, base, encombrement, disponibilité/documentation.
- Verdict attendu : 1368 pour plusieurs tasses ; 1358 pour compact ; Alicia comme alternative conditionnelle.
- Anti-patterns : ne pas supposer qu’électrique = programmable ; aucun test gustatif/thermique inventé ; ne pas figer un prix.
- Maillage : comparatif général, guides dosage/mouture.
- Structure : réponse → intérêt d’une moka électrique → tableau fonctionnel → limites → sources.
