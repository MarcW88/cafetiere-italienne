# Brief — meilleure-cafetiere-italienne

- Query : meilleure cafetière italienne
- Intention : comparaison transactionnelle / décision générale.
- Décision : aider à choisir selon plaque, capacité, matériau et niveau de finition.
- Scope : Moka Express, Venus, Moka Induction, Alessi 9090.
- Critères : compatibilité plaque, taille réelle, construction, valeur fonctionnelle.
- Verdict attendu : conditionnel, pas de gagnant universel.
- Angle : la plaque décide avant la marque.
- Preuves obligatoires : aluminium Moka Express, non-induction, inox/induction Venus selon taille, base bi-layer Moka Induction, inox/fond magnétique 9090.
- Anti-patterns : ne pas prétendre avoir testé ; ne pas attribuer un meilleur goût à un matériau ; pas de prix figés ; pas de score décoratif.
- Maillage : guide de choix, capacités, comparatifs induction/inox/design.
- Structure : réponse directe → tableau de décision → arbitrages produit → effet de la taille → sources.
