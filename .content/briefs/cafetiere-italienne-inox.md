# Brief — cafetiere-italienne-inox

- Query : cafetière italienne inox
- Intention : comparer des moka inox sans extrapoler des bénéfices non prouvés.
- Décision : Venus pour l’usage quotidien ; Alessi 9090/Menhir pour un choix premium/design.
- Scope : Bialetti Venus, Alessi 9090, Alessi Menhir.
- Critères : construction inox documentée, fond magnétique, simplicité, valeur de conception.
- Preuves obligatoires : inox 18/10, compatibilité induction documentée, caractéristiques distinctives 9090/Menhir.
- Anti-patterns : aucune promesse santé ; aucun claim “meilleur goût grâce à l’inox” ; ne pas dire inox = induction automatiquement.
- Maillage : guide aluminium ou inox, comparatif induction, comparatif design.
- Structure : réponse → ce que l’inox change réellement → trois modèles → verdict par usage → sources.
