# Brief éditorial — Quel café choisir pour une cafetière italienne ?

## Workflow

- URL : `/guides/quel-cafe-pour-cafetiere-italienne/`
- Mode d'entrée : `guide-analysis-workflow / AUDIT`
- Décision : `DEEP_REWRITE`
- Type dominant : `CHOICE`
- Rôle : aider à choisir un café compatible avec la moka puis un profil sensoriel, sans classement de marques ni faux “meilleur café”.
- Frontière : la mouture technique appartient à `/guides/mouture-cafetiere-italienne/`, le dosage à `/guides/dosage-cafe-cafetiere-italienne/`, le diagnostic amer/brûlé à `/guides/cafetiere-italienne-cafe-amer-brule/`.

## Intention principale

Répondre à « quel café choisir pour une cafetière italienne ? » en séparant clairement :

1. la compatibilité technique de la mouture ;
2. le choix grains vs pré-moulu ;
3. la composition Arabica / Robusta / mélange / décaféiné ;
4. la torréfaction comme préférence, pas comme règle de compatibilité ;
5. l'intensité commerciale vs la caféine ;
6. la conservation ;
7. une méthode d'essai qui ne change qu'une variable à la fois.

## Thèse

Le seul vrai hard gate du café est sa mouture. Une fois la mouture adaptée à la moka, composition, torréfaction, origine et format deviennent principalement des choix de profil et de contrôle. Il n'existe pas de “meilleur café moka” universel démontrable.

## Registre de preuves

### Bialetti — Coffee Beans Classico

Source : https://www.bialetti.co.nz/products/bialetti-coffee-beans-classico-500gm

Claims utilisables :
- une moka demande une mouture medium-fine, plus fine que drip et plus grossière qu'espresso ;
- les grains peuvent être utilisés avec plusieurs méthodes si la mouture est adaptée ;
- conservation recommandée : contenant hermétique, à l'abri de la lumière, chaleur et humidité, à température ambiante ;
- le réfrigérateur / congélateur peut introduire de la condensation ;
- l'indice d'intensité décrit richesse, profondeur, force aromatique et corps, pas la caféine ;
- Classico = 50 % Arabica / 50 % Robusta, intensité 8.

Classe : `PRIMARY_BRAND_STORE`.

### Bialetti — Coffee Buying Guide

Source : https://www.bialetti.co.nz/pages/bialetti-coffee-buying-guide

Claims utilisables :
- la gamme inclut des compositions différentes (100 % Arabica, mélanges Arabica/Robusta, décaféiné) ;
- l'intensité est présentée comme une échelle de goût, pas de caféine ;
- la gamme de cafés moulus est dédiée à la moka.

Classe : `PRIMARY_BRAND_GUIDE`.

### Bialetti — Perfetto Moka Decaffeinated

Source : https://www.bialetti.co.nz/products/bialetti-perfetto-moka-decaffeinated-250gram-bag-new

Claims utilisables :
- un café décaféiné peut être vendu avec une mouture explicitement conçue pour moka ;
- rappel des règles de conservation Bialetti ;
- intensité ≠ caféine.

Classe : `PRIMARY_BRAND_STORE`.

### Lavazza — Arabica vs Robusta

Source : https://www.lavazza.com/en/coffee-secrets/difference-type-arabica-robusta-coffee

Claims utilisables avec prudence :
- Arabica décrit comme généralement plus doux/aromatique ;
- Robusta décrit comme plus intense/terreux ;
- le Robusta contient généralement davantage de caféine que l'Arabica.

Classe : `PRIMARY_COFFEE_BRAND_EDITORIAL`.

Limite : ne pas reprendre la hiérarchie commerciale “Arabica = meilleure qualité”. Les descripteurs sont des tendances larges et ne prédisent pas chaque café.

### Lavazza — Qualità Rossa Ground

Source : https://www.lavazza.com/en/roast-and-ground-coffee/qualita-rossa

Claims utilisables :
- mélange Arabica / Robusta ;
- torréfaction moyenne ;
- café moulu ;
- usage annoncé pour moka, filtre et plunger.

Classe : `PRIMARY_MANUFACTURER_PRODUCT`.

Utilité : montre qu'une torréfaction moyenne peut être explicitement destinée à la moka ; ne permet pas de conclure qu'elle est “idéale” pour tous.

## Recherche d'intention / SERP

La SERP actuelle insiste sur :
- mouture medium-fine ;
- Arabica vs Robusta ;
- torréfaction medium / foncée ;
- grains vs moulu ;
- fraîcheur / conservation ;
- origine ;
- parfois des recommandations très tranchées par pays d'origine ou “meilleurs cafés”.

Décision éditoriale : couvrir les sous-questions légitimes mais refuser les règles non démontrées du type “Éthiopie = mauvais en moka”, “Brésil = meilleur” ou “torréfaction foncée obligatoire”.

## Structure justifiée

1. Réponse courte : mouture → format → composition → torréfaction.
2. Mouture comme hard gate.
3. Grains vs moulu : contrôle vs simplicité.
4. Arabica / Robusta / mélange : tendances, sans hiérarchie.
5. Torréfaction : variable de goût, pas règle de compatibilité.
6. Intensité ≠ caféine.
7. Origine / blend / décaféiné : pas de règle d'exclusion moka.
8. Conservation : éviter d'ajouter une variable parasite.
9. Méthode d'essai à une variable.
10. Sources.

Valeur autonome :
- ordre de décision ;

- démystification intensité / caféine ;
- méthode d'essai contrôlée ;
- refus des raccourcis par origine ou espèce.

## Claims interdits

- “100 % Arabica = meilleur café” ;
- “Robusta = mauvaise qualité” ;
- “torréfaction foncée obligatoire pour moka” ;
- “intensité 9 = plus de caféine” ;
- “tel pays d'origine ne convient pas à la moka” sans protocole solide ;
- classement de marques / produits ;
- promesse de goût garantie ;
- faux test ou faux retour d'expérience.
