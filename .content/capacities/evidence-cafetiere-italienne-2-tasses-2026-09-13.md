## Question à résoudre

Que signifie réellement « 2 tasses » en volume, et dans quels cas ce très petit format est-il cohérent — notamment sur induction ?

## Faits vérifiés

- **Bialetti Moka Express 2** : ~90 ml de café préparé ; base ~8 cm. Source : https://www.bialetti.co.nz/products/moka-express
- **Bialetti Venus 2** : ~85 ml ; base ~8 cm ; explicitement non compatible induction. Source : https://www.bialetti.co.nz/products/bialetti-venus-induction-copper
- **Bialetti Moka Induction 2** : ~100 ml ; base ~9,5 cm ; induction, avec consigne fabricant de vérifier le diamètre minimal accepté par la plaque. Source : https://www.bialetti.co.nz/products/bialetti-moka-induction-bi-layer-black
- **Cecotec Moking 200** : capacité annoncée 100 ml pour 2 tasses. Source : https://www.storececotec.fr/fr/cafetieres-italiennes/moking-200
- **Barazzoni La Caffettiera inox 2** : variante 2 tasses, Ø annoncé 8,5 cm, compatible induction ; la fiche consultée ne publie pas de volume en ml. Source : https://www.barazzoni.it/en/products/la-caffettiera-caffettiera-acciaio-inox-830008002
- **Bialetti Moka Express 3** : ~130 ml ; utile comme taille adjacente si 85–100 ml est trop peu. Source : https://www.bialetti.co.nz/products/moka-express
- **Bialetti Moka Exclusive Induction 3** : ~130 ml ; base ~9 cm ; induction. Source : https://www.bialetti.co.nz/collections/stainless-stovetop/products/bialetti-moka-exclusive-induction-grey

## Conclusions sûres

1. Dans les références 2 tasses documentées ici, le volume se situe autour de 85–100 ml ; ce n'est pas une conversion universelle pour tout le marché.
2. « 2 tasses » ne signifie ni deux mugs ni deux personnes.
3. Sur induction, le **diamètre de détection** peut devenir une contrainte dure plus importante que l'étiquette 2 tasses.
4. Une variante 2 tasses peut être induction (Moka Induction, Barazzoni) ou non (Venus) : la taille ne prédit pas la plaque.
5. Si le besoin régulier dépasse ~100 ml, il faut considérer une taille adjacente (par ex. 3 tasses ~130 ml) plutôt que forcer la catégorie 2.
