## Question à résoudre

Que couvre réellement l'étiquette « 4 tasses » en ml et comment décider si ce palier est plus cohérent qu'une taille adjacente ?

## Faits vérifiés

- **Bialetti Moka Induction 4** : ~150 ml ; base ~10 cm ; induction avec vérification du diamètre minimal de la plaque. Source : https://www.bialetti.co.nz/products/bialetti-moka-induction-bi-layer-black
- **Bialetti Venus 4** : ~170 ml ; base ~9,5 cm ; induction. Source : https://www.bialetti.co.nz/products/bialetti-venus-induction-copper
- **Bialetti Moka Express 4** : ~185 ml de café préparé ; base ~9,5 cm ; modèle classique non induction directe. Source : https://www.bialetti.co.nz/products/moka-express
- **Cecotec Moking 400** : capacité annoncée 200 ml pour 4 tasses. Source : https://www.storececotec.fr/fr/cafetieres-italiennes/moking-400
- **Grønenberg inox 4** : capacité annoncée 200 ml ; induction ; le fabricant indique un champ induction à partir de Ø 9,5 cm. Source : https://groenenberg-coffee.de/products/espressokocher-induktion-4-tassen
- **Barazzoni La Caffettiera inox 4** : variante 4 tasses, induction ; la fiche consultée ne publie pas de volume en ml. Source : https://www.barazzoni.it/en/products/la-caffettiera-caffettiera-acciaio-inox-830008002
- **Bialetti Moka Express 3** : ~130 ml ; **Moka Express 6** : ~250 ml. Source : https://www.bialetti.co.nz/products/moka-express

## Conclusions sûres

1. Sur les références vérifiées, « 4 tasses » couvre environ **150 à 200 ml** : l'écart est suffisamment important pour changer une décision de taille.
2. Il est faux de présenter 4 tasses comme une valeur standard autour de 170–180 ml.
3. L'induction reste modèle- et diamètre-dépendante ; Grønenberg documente explicitement un minimum de champ de 9,5 cm.
4. Pour un besoin autour de 120–140 ml, une 3 tasses peut être plus cohérente ; pour ~230–300 ml, la 6 tasses devient la taille voisine logique.
5. Cette page doit expliquer un **intervalle de capacité**, pas départager les marques.

## Claims interdits

- « 4 tasses = 4 personnes. »
- « Une 4 tasses fait toujours ~180 ml. »
- « Toutes les 4 tasses sont induction. »
- « Le modèle X est la meilleure 4 tasses. »
